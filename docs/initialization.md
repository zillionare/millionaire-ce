# 初始化与数据准备

首次打开服务网页进入六步 wizard。建议保留本机访问与默认端口，先完成日线回测路径。

## 六步向导

| 步骤 | 要做什么 | 完成后应看到什么 |
| --- | --- | --- |
| 欢迎 | 阅读本版初始化内容，点击“下一步” | 进入运行环境设置 |
| 运行环境 | 确认“数据存储位置”、监听端口与本机访问设置 | 目录配置保存；该目录对服务运行账户可写 |
| 管理员密码 | 输入并确认自己的密码 | 创建 `admin` 账户，之后用该密码登录 |
| 数据源配置 | 填写 Tushare token、起始日、首次下载年数，点击“检测并继续” | 显示各接口权限与字段检查结果，此时不批量下载 |
| 实时行情配置 | 如尚无可接入的实时源，选择腾讯演示、已启用的用户扩展或暂不启用 | 已检测到可接入的 Tushare 实时快照时，CE 自动跳过此步 |
| 数据准备与完成 | 确认配置，点击“开始下载历史数据”；成功后进入系统 | 下载阶段、进度及结果明确显示；成功前不能跳过下载 |

系统没有预设管理员密码。密码强度提示用于帮助选择密码，不要沿用教程中的测试密码。
Windows/Ubuntu 原生服务使用独立运行账户或系统账户，你的桌面用户能写某个目录，
不代表后台服务也能写。优先使用安装器预置目录，路径见[运维](operations.md)。

监听端口和“只允许本机访问”设置在后台服务重启后生效。初始化后，管理员可在
“系统维护 → 系统设置 → 服务访问”修改它们，再通过菜单栏或托盘控件重启服务。
取消仅本机访问会监听所有网络接口，局域网用户需登录；使用时请信任所在网络。

## Tushare token 与权限

从 [Tushare 账户页面](https://tushare.pro/user/token)取得 token，在 wizard 或
“系统维护 → 数据源”中配置。token 可用与具体接口有权限是两回事：日历、日线、
涨跌停、ST、指数等请求都受账号权限、历史范围和频率限制。

测试/CI 可以读取 `TUSHARE_TOKEN` 环境变量；后台服务不会自动继承你在另一个终端里
设置的环境变量，最终用户应确认网页中配置的数据源已保存。不要把 token 放进策略、
截图、报错附件或提交到 Git。

第 4 步会检查日历、证券列表、日线、复权因子、历史涨跌停、ST、市值换手、
指数日线与成分权重的小样本。ST 和历史涨跌停是正确回测所需的数据，不能在无权限时
静默省略。若接口明确返回权限不足，页面提示到 Tushare 权限中心提升积分或开通对应权限，
处理后再次点击“检测并继续”会重新检测，即使 token 没有变化。积分或付费要求以
[Tushare 当前说明](https://tushare.pro/document/1?doc_id=108)及接口实际响应为准。

连接异常、限频、无效 token、空响应和字段缺失分别显示；空响应不代表账号必须升级。
必要接口未通过时，先修正原因再继续。检查结果绑定 token 与首次下载窗口，短期缓存
15 分钟；它只证明少量样本可用，完整覆盖仍由下载任务验证。

实时快照与实时分钟是可选检查项，未通过不影响只做研究回测。

“数据起始日”限定整体回补起点；“首次下载时长（年）”决定首次下载窗口。
保留较短窗口可以更早验证使用路径，但下载时间仍取决于请求量、权限和限速。
后续回补由持久化任务编排器处理，不把首次导入完成等同于整个市场历史已齐全。

## 实时行情选择

仿真需要至少每分钟更新的实时行情，包含最新价、当日涨跌停及复权基准。
`pre_close` 还需结合历史原始收盘价与历史复权因子使用，不能仅凭一个昨收字段
计算完整复权。CE 不提供真实交易；millionaire pro 或用户宿主可复用行情接口。

本版新增 Tushare 官方 [`rt_k` 实时快照](https://tushare.pro/document/2?doc_id=372)
发布者：按交易时段每 60 秒读取已订阅 A 股，并取得当日 `stk_limit`。第 4 步检查到
其权限和必要样本字段可用时，自动选用该源、跳过第 5 步，不开启腾讯演示计时。
运行时仍检查行情时间戳、时效和同日限价，拒绝过期或不完整报价。
权限检测本身不证明交易时段内持续更新，也不证明所有标的覆盖；盘外无有效样本时可在
交易时段重检，或暂不启用实时源。当前未接入 Tushare 指数实时行情。

[`rt_min` 实时分钟](https://tushare.pro/document/2?doc_id=374)与 `rt_k` 是两项独立权限。
本版检测分钟权限但尚未自动接入该接口；只有分钟权限的用户可通过
[自定义行情扩展](quote-extensions.md)接入，无需为使用框架额外购买快照权限。
完整分钟接入和多源配置见[下一版规划](roadmap.md)。

已有服务修改实时源后，需通过服务控件重启服务使其生效；新安装在完成初始化后装配。

## 腾讯演示源

默认不勾选也能下载历史数据和做回测。选择启用时，从首次启用时刻起固定 30 天，
关闭、重启、升级、重跑 wizard 都不续期。到期自动停用，不能在 wizard 中再次开期。
继续仿真时接入自己的[行情扩展](quote-extensions.md)。

## 下载完成的判断

在“系统维护 → 数据维护”中分别检查交易日历、股票列表和行情数据。
确认目标证券及回测日期确有数据，尤其是开始日前的因子/均线预热区间。
30 分钟策略需要分钟数据，不能用日线下载成功替代。

任务失败或中断时先看错误原因：token/权限、网络、限频、存储空间或数据覆盖。
修正原因后从对应维护页重新发起同步；任务会检查缺口，不能通过重建空库使错误消失。
服务退出后的中断状态会保留，旧任务状态不代表仍有线程在执行。

首次准备完成后，继续[第一次回测](backtesting.md)。
