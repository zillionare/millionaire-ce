# 第一次回测与报告

先用 `DualMAStrategy` 验证流程，再运行更耗数据和算力的 LightGBM 策略。
双均线示例在快线上穿慢线时买入、下穿时卖出；不是盈利承诺。

## 确认数据

选择本机**确有数据**的连续三个月，且开始日前至少有 22 个交易日的日线预热数据。
示例证券是 `000001.SZ`。如使用 `2024-01-02` 至 `2024-03-29`，须先有该区间及
2023 年 12 月的行情；首次仅下载最近一年的用户应选择自己已下载的日期。

在“系统维护 → 行情数据”检查覆盖范围。非交易日起止会按交易日对齐；结束日可能被
已有日线覆盖截断，因此报告实际区间也要核对，不能只看输入表单。

## 配置并运行

1. 打开“策略”，从自动加载的内置策略中选择 `DualMAStrategy`。
2. 打开回测向导，设置开始/结束日期、初始资金和策略参数。
3. 确认周期显示“日线”；这是策略声明，不是可切换的运行选项。
4. 查看交易参数，进入后续因子/风险选择步骤，再提交回测。

建议第一次使用以下配置：

| 项目 | 值 | 含义 |
| --- | --- | --- |
| 初始资金 | `200000` | 元 |
| `fast` | `5` | 快线窗口，交易日 |
| `slow` | `20` | 慢线窗口，交易日 |
| 默认证券 | `000001.SZ` | 内置示例的默认值 |
| 默认单次投资 | `100000` | 元；不能超过可用资金 |

内置示例默认表单只声明 `fast`、`slow`。改变证券或投资额可通过自己的策略默认配置
声明 `symbol`、`invest`，见[策略编写示例](strategies.md)，不要寻找并不存在的必填控件。

交易参数当前提供佣金、卖出印花税、双边过户费与最低佣金。比例使用小数，
例如 `0.0001` 为万分之一。比较实验时保持相同费用和成交时序，并记录所有改动。
CE 没有内置风险程序可选，保持空选择即可；它不代表 T+1 等交易规则被关闭。

## 判断是否成功

回测报告可从策略详情或“回测管理”重新打开。四个页签是：

| 页签 | 先看什么 |
| --- | --- |
| 收益概述 | 实际区间、运行状态、净值曲线、收益/回撤等指标；留意成交时序标记 |
| 交易详情 | 成交对、数量、价格、费用与买卖时刻；点击可查看 K 线和解释面板 |
| 每日持仓 | 股数、可用股数、市值和浮盈；买入当日可用股数受 T+1 限制 |
| 日志输出 | 策略初始化、信号、运行结束或错误；需要跨重启查看时启用保存日志 |

如果任务失败，报告中的部分结果不能作为一份完整回测使用。没有成交则先看预热、
交叉信号和拒单原因，不能用“无成交”直接推断撮合器失效。

收益指标依赖区间和年化口径。短区间的年化收益、夏普等可能非常不稳定；
按日期对齐后比较，并结合费用、换手和回撤阅读。后续做[参数优化](optimization.md)时
还要保留样本外区间。

## 保存实验与进入仿真

保留报告 ID、策略源码版本、参数、实际区间、费用及数据版本。重新运行会产生新的
实验，不要把两份不同配置的结果当作同一个策略版本。

回测完成后从对应记录选择“转仿真”，沿用这份策略配置。步骤见
[仿真与持续运行](paper-trading.md)；执行语义见[成交时序](execution.md)。
