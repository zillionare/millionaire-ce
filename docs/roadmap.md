# 下一版：策略审计、因子研究与月线示例

状态：v0.4-001 的源码主体已实现并通过本地可重复验收（AC 矩阵 39/40，
`AC-4014` 等待三平台 CI）。审计入口目前覆盖本页列出的固定因子管线和适配路径；
完整训练标签/模型、多来源柜台归因和复权月线仍需独立验收。对外发布仍以 CI
三平台测试、完整审计/变异门禁和 Release 流程为准。本页不改变 `0.3.1` 已发布版本的
安装方式或发布条件。正式规格位于源码仓库
`.louke/project/specs/v0.4-001-strategy-audit/`；目录中的版本是版本标识，
实际发行版本以后续 Release 为准。

## 为什么单独发布

本版先交付明确的策略/数据/交易合同和可持续运行路径。下一版在这些基础上增加
系统化证据：帮助用户检查 AI 编写的因子/策略，并解释最终收益。
新审计功能适合作为独立版本，不把它误记成本版已经完成的功能。
已经发现的交易或账户正确性缺陷仍按当前缺陷处理，不因审计延期而获得豁免。

## 四类审计

| 能力 | 需要发现的问题 |
| --- | --- |
| 未来扰动 | 修改决策时刻之后才可得的数据，历史特征/模型/信号应逐位不变，覆盖缓存和选股池 |
| 随机对照与植入信号 | 随机因子/置换标签的统计表现符合零假设，已知强度的信号可按预定置信区间恢复 |
| 金标准与对拍 | 3 只股票 × 10 个交易日的人工基准、独立公式及参考指标库对照 |
| 不变量与变异测试 | 资金/数量/T+1 等守恒；故意植入未来函数、漏费用、错误周期等缺陷后审计必须报错 |

统计测试使用预先固定的种子、样本量、IC 类型、阈值和检验功效。
随机多头在上涨市场可以赚钱，因此真实数据看匹配基准后的超额表现；
只有在零漂移、受控暴露的合成市场中，随机策略的净收益才应接近负成本。
停牌允许保留原持仓，但不应发生正常撮合；首个资金快照净值为 1，费用后的日终可低于 1。

## 收益归因

增加与模型无关的账户、策略、资产、交易和成本收益分解，对账权益变动；
明确现金流、分红/拆股、未分配来源、基准和剩余项，处理多期收益贡献链接。
SHAP 继续解释预测贡献，与收益归因分别展示。

## 因子研究与月线示例

下一版也完善已有的[轻量因子检验](factor-analysis.md)：规范输入/预热/样本排除、
Pearson/Rank IC、分层与分期报告及 AI 可读诊断，不重复建立重型平台。

因子将成为策略之前的一级入口，提供分组侧栏、因子卡片与检验报告两个 tab。
每个因子可保存一套跟踪方案；后台在数据维护后自动更新，页面直接读取最近完整快照。
不同持有期分别显示评价截止日期，明确前瞻收益成熟造成的滞后；临时检验与自动跟踪
分开保存。默认参数不代表最优或盈利建议，普通 t 值也不能代替独立审计。
原 003 因子研究计划已合入 001，细则在
`.louke/project/specs/v0.4-001-strategy-audit/factor-research.md`。自动跟踪与
自定义检验都已落到持久任务队列，包含状态、租约、取消和预算；自定义检验在可终止
子进程中计算。

真正固定 `1M` 周期的 3/12 月均线示例已交付：月线由权威日历聚合，区分闭合/形成中/
缺月末，信号在下月首个实际交易日执行；跨月意图持久化并按键去重，回测、Paper 和
HTTP 模拟柜台共用同一提交路径并用人工账户事实对拍。详见[月线均线策略](monthly-strategy.md)。

## 面向 AI/agent 的结果

规划输出机器可读 JSON 与可读报告，定位首个错误时刻/标的，给出输入、预期/实际值
和复现条件。通过结论仅对对应源码、配置、数据和审计配置有效。
已登记的官方因子/策略模板需通过相应审计，空报告或跳过不能充当发布证据。

这些能力不增加 CE 真实交易功能，也不包含三重障碍等私有风险程序。
