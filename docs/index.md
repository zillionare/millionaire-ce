# Millionaire CE 用户手册

Millionaire CE 是面向 A 股的开源量化框架。你可以从自带策略开始，把精力放在因子和
交易逻辑上，复用历史数据、回测、参数优化、预测解释及持续仿真的流程。

本手册中，**millionaire** 是社区版与专业版的合称；**millionaire-ce（CE）** 指社区版，
**millionaire pro** 指专业版。介绍共有设计时使用 millionaire，涉及版本专属能力时明确标注。

## 核心能力

**策略在回测、仿真和实盘间无感迁移** millionaire 把交易和撮合从策略逻辑中剥离出来，使用统一的交易代理接口，再通过适配器提供不同运行模式下的交易、撮合实现。

这种设计，让遵循框架接口的策略可以沿用同一份交易逻辑，省去切换模式时的代码移植。CE 已提供回测、仿真和独立 HTTP 模拟柜台，用模拟方式验证三条执行路径的一致性；真实交易由 millionaire pro 或用户宿主扩展接入。

无感迁移还包括自动带入回测时的策略配置：CE 从回测转入仿真时默认沿用原参数，用户可以重新设置仿真本金。

**不锁定券商** 实盘接口的门槛和接入标准始终在变，每一次改变，都可能导致你之前使用过的量化框架不可用。

我们提供了统一的 HTTP 交易接口将柜台与策略进程分开，因此你可以根据券商实际开放的接口和接入条件，自行适配柜台。即使你不熟悉编程，也可让 AI 依据接口、参考实现和验收用例协助完成。CE 提供适配边界和模拟柜台，真实账户接入由 millionaire pro 或用户宿主扩展装配。请参考[柜台适配指南](broker-adapters.md)了解路径。

**不锁定数据源** 做量化交易，数据是最大的依赖。可靠的数据源一直在变，即使还在提供量化数据的，价格也一直在变。因此，好的量化框架，必须保持对新的数据源的高度可适配性。

在 millionaire 中，适配器将供应商数据转换为统一字段、时间和单位，历史数据进入标准存储，实时行情进入行情 Hub。我们把这套项目内的数据约定称为 SQEP（标准行情交换协议）。接入新的数据源，从编写适配器开始，AI 也可以依据接口和样例帮助完成。详见[标准行情交换协议](SQEP.md)。

**策略防呆** 即使你是独立研究者，策略的用户就是你本人，也很难拒绝虚假但好看的回测报告。millionaire 通过多种防呆设计，帮助你减少执行假设和周期配置上的错误。详见[策略防呆](execution.md)。

1. 自带成交时序、T+1、涨跌停和资金检查；涨跌停检查需要有效的限价数据。
2. 策略周期是固有属性。日线策略始终按日线运行，30 分钟策略始终按 30 分钟运行。这会降低策略编写难度，避免跨周期时引入的谬误。

**自带策略框架，轻松拓展策略** millionaire-ce 自带基于 LightGBM 的示例策略，串起因子计算、模型训练、选股调仓、参数优化与 SHAP 预测归因。你可以从设计、选择因子开始，复用已有研究流程，拓展自己的策略。见[因子与 LightGBM](factors-and-ml.md)。当前归因解释因子如何影响模型预测，完整收益归因列入[下一版规划](roadmap.md)。

**主策略与风控策略独立设计，自由叠加** 一般来说，风控策略比较固定，而主策略千变万化。在 millionaire 中，兼容的风控程序只要创建一次，就可以与多个主策略叠加。开发主策略时，无须反复编写风控逻辑，从回测起就能观察叠加后的表现。CE 已提供注册、兼容性检查、优先级及回测/仿真生命周期；用户注册适配器后，即可选择自己的风控程序。详见[风控扩展契约](design/risk_program_selection.md)。

基于三重障碍法的内置止盈止损风控属于 **millionaire pro** 的能力范围。CE 默认风控注册表为空，不附带该程序。

**尾盘竞价模式，小资金更友好** 对日线策略，你可能常常遇到这样的困惑：收盘时策略发出信号，却要等到次日开盘才能买入，错过了希望参与的尾盘窗口。millionaire 支持明确的 Cheat-on-Close 模型：回测按当日收盘模型撮合，仿真在收盘前依据当时可见行情计算并提交委托，让你可以研究尾盘交易思路。

这种模式可以缩短信号到委托的等待，但当日买入仍遵守 T+1。最终收盘价在决策时尚不可知，即使资金较小，真实成交也受排队、流动性和滑点影响。模型前提见[成交时序](execution.md)。

**影子伴行（Shadow-Run），双实例对照，运行效果看得更清楚** 策略进入持续运行后，效果不如回测，究竟是市场变了，还是执行过程产生了差异？CE 为日线策略提供双实例对照：仿真实例依据当前行情运行，回测实例在当天收盘、历史数据就绪后，用同一策略类和配置、当日有效模型（若策略使用模型）回放，再对照两个账户的净值、回撤与每日差额。

日线回测需要完整的当日行情，收盘后运行正是这一周期自然的对照时点。跟踪任务在转入仿真时默认建立，帮助你持续发现执行差异。目前完整对照覆盖日线，30 分钟影子生命周期仍待补齐。使用入口与前提见[仿真与影子对照](paper-trading.md#shadow-run)。

## 阅读前确认

本手册对应 `0.3.1` 交付线。支持 macOS Apple Silicon（ARM64）、Ubuntu x86_64、
Windows x64；原生包自带运行环境。安装包是否已经发布，以
[Releases](https://github.com/zillionare/millionaire-ce/releases)中的实际文件为准。

CE 不提供真实交易，不内置三重障碍等私有风控程序。腾讯实时演示源默认关闭，
用户可选择一次固定 30 天演示，到期使用自定义行情扩展。
完整收益归因与 AI 审计尚属[下一版规划](roadmap.md)，不是本版已有功能。
更完整的交付与验证范围见[CE 能力边界](scope.md)。
