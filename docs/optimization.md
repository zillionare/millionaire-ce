# 参数优化

参数优化使用与回测相同的运行器，支持网格枚举、随机采样及按时间划分的样本内外
指标。它帮助比较配置，不能替代样本外验证，也不能把日线策略优化成 30 分钟策略。

## 第一次优化

1. 先按[回测教程](backtesting.md)确认某个固定配置可以运行。
2. 从策略详情或策略行打开“参数优化”。
3. 选择目标、搜索方式、日期、样本内占比、初始资金、并发数和时间预算。
4. 在“参数取值（仅策略参数）”填写候选，点击“开始优化”。
5. 等待结果，检查每个候选是否失败，再比较样本内与样本外指标。

输入一个值表示固定该参数，多个候选可以用逗号分隔。例如双均线：

| 参数 | 候选 |
| --- | --- |
| `fast` | `3, 5` |
| `slow` | `20, 30` |

网格应有四种组合。先小网格确认候选解析，再扩大搜索。ML 可先研究 `top_k`、
`train_window`、`retrain_days`，不要一次同时改变证券池、因子公式和所有模型参数。
周期、费用及其他固定前提应与基准保持一致。

## 选项含义

| 选项 | 说明 |
| --- | --- |
| 网格枚举 | 遍历候选组合，组合数量为各参数候选数的乘积 |
| 随机采样 | 从参数空间抽样；固定种子和候选空间才能复现实验 |
| 优化目标 | 夏普、年化收益、Calmar、Sortino、最大回撤等；最大回撤的优化方向与收益类指标不同 |
| 样本内占比 | 按时间顺序切分，默认 0.7；样本外位于其后 |
| 并发进程数 | 控制资源使用，首次建议 1 或 2；训练仍可能占用多个计算线程 |
| 时间预算 | 分钟；0 表示不限，停止后保留已经完成的候选结果 |

样本内外是同次回测的时间分段结果；训练策略可能按自身规则在后续时段重训。
这不是对任意模型自动完成独立嵌套交叉验证。训练窗口、标签成熟和选池必须继续遵守
策略的时间约束。

## 如何使用结果

先排除错误、区间不符和数据不足的行。查看多个目标与月度表现，不只追逐样本内
第一名。确认候选在样本外是否显著退化，再将选中参数回填回测，生成完整报告核对。

多轮观察样本外并据此继续调参，也会把它变成开发数据；保留最后没有用于选参的区间。
短区间、几乎无交易或缺失指标不能解释为“最优”。
任务状态和错误见当前优化页；进程中断后不要把残留运行标记当成计算仍在继续。
