# 因子研究

因子是策略之前的独立研究阶段。当前版本提供“因子”一级入口：先看因子卡片理解
计算口径，再用检验报告判断样本关联，最后为每个因子保留一套自动跟踪方案。
研究统计描述的是因子值与未来收益的关联，不是含费用、涨跌停、T+1 和可成交性
约束的策略净收益。

## 网页操作

1. 打开顶部“因子”进入因子总览；侧栏按因子分组，可搜索因子名称或 ID。
2. 点击因子查看“因子卡片 / 检验报告”两个 tab。有跟踪快照时默认打开报告，
   没有快照时默认打开卡片。
3. 在“跟踪设置”中选择回看窗口、主持有期、对照持有期和买入价口径。因子公式
   参数固定属于因子定义，不能在这里修改；每个因子只保留一套当前方案。
4. 每日收盘后（当前定时为 18:45）后台更新已启用因子的快照；服务启动时会补查
   上次未完成或已落后于行情的跟踪。页面只读取持久化结果，不在请求路径中重算
   全市场。首次使用可点击“立即建立跟踪”。
5. “自定义检验”可临时指定固定日期区间和持有期。请求先进入持久任务队列，由受限
   并发 worker 在可终止子进程中计算，页面显示排队、计算、成功、失败或取消状态，并
   提供取消入口；结果明确标记为临时报告，不会自动修改跟踪方案或快照。需要保留时，
   再显式确认滚动窗口并“设为跟踪方案”。任务有执行时间、面板规模和重试预算；服务
   停止时回收租约，中断任务不会发布半成品。
6. 只有成功的快照会替换当前结果；本次数据不足或计算失败时保留上一次成功快照，
   并同时显示本次状态。行情、交易日历、证券池/指数成分或计算依赖的来源版本变化
   （即使行情最新日期不变）都会使快照显示“行情已更新，待跟踪”，后台排队重算；
   旧输入版本不能覆盖新版本结果。来源版本暂时不可读取时显示“来源版本不可用”，
   不会把未知来源当作已验证最新。每个方案的窗口、预热期和参数只进入自己的缓存键，
   不同回看窗口共用同一原始来源版本，不会互相标陈旧。

默认跟踪方案为 3 年回看、主持有期 5 日、对照持有期 1/3/5 日、开盘价。
持有期越长，评价截止日越滞后；页面分别显示每个持有期的 `as_of_date`，
计算时间不是评价截止日期。

## 结果口径

| 结果 | 含义 |
| --- | --- |
| 截面 Rank IC | 同日因子排名与前瞻收益排名的 Spearman 相关；并列使用平均秩 |
| 截面 Pearson IC | 同日因子原始值与前瞻收益的线性相关；与 Rank IC 分序列、分汇总 |
| ICIR / 年化 ICIR | `mean / sample_std`，年化按 `sqrt(252)`；同时保留普通 t 值 |
| IC 均值、普通 t 值、有效天数 | 汇总每日 Rank IC；少于 100 个有效证券的截面不进入统计 |
| 十分位前瞻收益 | 先算每个信号日的等权平均前瞻收益，再对可比较日期等权汇总 |
| D1-D10 | D1 为原始因子值最低组、D10 为最高组；使用两端都有效的共同日期，不自动翻转符号 |
| 持有期衰减 | 各持有期使用各自成熟样本；共同有效日期不足时不做误导性比较 |
| 年度稳定性 | 按样本年份汇总 Rank IC，用于观察关系是否随年份变化 |

普通 `t_naive = mean(IC) / (sample_std(IC) / sqrt(n_days))`，少于两日或方差为零时
无定义，不会输出 Infinity。ICIR 使用同样的样本标准差，年化约定为 `sqrt(252)`；这些
都是描述性统计，未调整重叠持有期的序列相关和多重选择，不能仅凭 `|t| > 2` 认定因子有效。
研究核心允许显式 `interval` 与 `holding_bars`；非日线不得把一个月偷换成 20/30 个交易日。
批量研究为每个因子独立保存有效样本和排除原因，缺失因子不会改变其他因子结果。

## 前瞻收益与成熟样本

因子在 `t0` 收盘后可用。默认以开盘价为价格字段：`t1` 开盘进入，
`t(h+1)` 开盘退出；`holding_days=1` 表示 `t1 → t2`，不是 `t0` 收盘到 `t1` 收盘。
因子值必须在其入场时刻之前可用：开盘价口径按入场日 09:30、收盘价口径按 15:00
（交易所时区）比较；只有日期没有时刻的数据按当日结束处理，不能用于当日入场。
晚于入场才发布的因子行会被排除并计入 `late_factor`，不能用事后回填的因子构造
历史 IC。标签只有在进出价格及其可用时间均满足本轮数据截止要求后才成熟。尾部
没有足够未来交易日的行不进入统计；不会按自然日或直接减 h 补造样本。

跨停牌跳日的样本依据权威交易日历排除；网页与自定义检验使用交易所日历计算
成熟度，某交易日全市场缺数据时不会自动压缩持有期。自建面板应提供完整市场
交易日历及交易日序号。输入须按证券、日期排序，日期/证券键唯一，并保持明确的
复权口径。

## Python API

以下在源码开发环境运行。日期仅为例子，需预先下载相应日线及证券池数据。

```python
import datetime

from quantide.data import init_data
from quantide.factors.alphatest import load_factor_panel
from quantide.factors.research import HorizonRequest, study_horizon

init_data()  # 使用已保存的行情目录；也可显式传入目录。
start = datetime.date(2024, 1, 2)
end = datetime.date(2024, 3, 29)
panel = load_factor_panel(start - datetime.timedelta(days=140), end)
result = study_horizon(
    panel,
    HorizonRequest(
        factor="ma20_slope",
        holding_days=3,
        start=start,
        end=end,
        data_cutoff=panel["date"].max(),
        price="open",
    ),
)
print(result.rank_ic.as_dict())
print(result.deciles.as_dict())
```

`quantide.factors.research` 提供 `study_horizon`、`common_cohort` 等版本化统计；
旧 `quantide.factors.alphatest` 保留为兼容 API 和命令行入口。自定义因子可以直接
放入面板的新列后研究，不必先加入内置 ML catalog。旧 CLI 的池化十分位口径与
新研究口径不同，比较结果时需注明所用模块和版本。

```bash
python -m quantide.factors.alphatest --start 2024-01-02 --end 2024-03-29 \
  --factors ma20_slope bias_20 --holdings 1 3 5 --price open
```

用 `--data-home` 指定行情目录；默认读取配置。原生安装用户优先使用网页，
无需另装 Python。

## 怎样解释结果

正/负 IC 表示本样本的同向/反向关联，不证明因果关系或样本外盈利。
非线性因子的零 RankIC 也不自动等于无用；先看覆盖、空值、预热和样本诊断，
再看符号与年度稳定性，最后放入含成本的[策略回测](backtesting.md)。
