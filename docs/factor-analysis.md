# 极简因子分析

本版已有轻量单因子检验模块 `quantide.factors.alphatest` 和“因子台账”页面。
可以先检查因子与前瞻收益的关系，再决定是否放入 LightGBM；不需要先训练模型。

## 目前能做什么

| 结果 | 含义 |
| --- | --- |
| 截面 Rank IC | 每个交易日对因子值和前瞻收益做 Spearman 相关；并列值使用平均秩 |
| IC 均值、t 值、有效天数 | 汇总每日 Rank IC；少于 100 个有效证券的截面不进入统计 |
| 十分位前瞻收益 | 按同日因子值分组，计算各组样本的平均前瞻收益 |
| 分年 Rank IC | 检查不同年份中的关系是否稳定 |
| 多因子/多持有期比较 | 批量分析因子，分别处理各自缺失值；可用 1、2、3、5、10、20 日等窗口 |

这是一套研究统计，不是含费用、涨跌停、T+1 和可成交性约束的组合回测。
分组平均收益不是资金曲线，也不能当作策略收益归因。

## 网页操作

1. 打开“系统维护 → 数据维护 → 因子台账”。
2. 选择已有数据覆盖的起止日期、持有期和少量因子。
3. 点击“开始检验”，查看 `IC / t`、分组差与年度结果。
4. 记录区间、数据、因子版本和样本量，再与其他窗口比较。

页面默认日期不代表本机已下载对应数据；首次只有最近一年数据时应自行调整。
当前年度展示列固定为 2023–2026；其他年份可通过 Python API/CLI 查看完整结果。
同一进程会缓存相同区间、持有期和因子集的结果；行情更新后应重启服务再做比较。
页面中的分组差按 **D1 − D10** 展示，并非做多最高组的 D10 − D1。
并列值不会强行拆开，可能出现空分组；缺少 D1/D10 时不显示该差值。

## 前瞻收益的时间口径

默认以 `open` 为价格字段：因子日期为 `t0`，在 `t1` 开盘进入，在 `t(N+1)` 开盘退出。
`holding_days=1` 表示 t1 开盘到 t2 开盘，持有一个交易日，不是 t0 收盘到 t1 收盘。
尾部没有足够未来数据的行不进入检验。

跨停牌跳日的样本依据交易日序号 `di` 排除。自建面板应提供完整市场交易日序号；
默认从面板所有日期构建的序号无法发现“所有证券都缺了同一天”的情况。
输入须按证券、日期排序，日期/证券键唯一。价格和因子应保持明确的复权口径。

## Python API

以下在源码开发环境运行。日期仅为例子，需预先下载相应日线及证券池数据。
先加载预热数据计算因子，再裁掉预热期；保留区间尾部用于成熟前瞻收益。

```python
import datetime

import polars as pl

from quantide.data import init_data
from quantide.factors.alphatest import format_report, load_factor_panel, study_single_factor

init_data()  # 使用已保存的行情目录；也可显式传入目录。
panel = load_factor_panel(datetime.date(2023, 11, 1), datetime.date(2024, 3, 29))
panel = panel.filter(pl.col("date") >= datetime.date(2024, 1, 2))
result = study_single_factor(panel, "ma20_slope", holding_days=3, price="open")
print(format_report([result]))
```

自定义因子可以直接放入面板的新列后调用 `study_single_factor`，不必先加入内置 ML
catalog；要求至少有 `date`、`asset`、价格列和因子列。`n_rows` 是收益有效的面板行数，
不保证每行都有有效因子并进入 IC；最终还要看有效截面天数。

## 命令行

```bash
python -m quantide.factors.alphatest --start 2024-01-02 --end 2024-03-29 \
  --factors ma20_slope bias_20 --holdings 1 3 5 --price open
```

用 `--data-home` 指定行情目录；默认读取配置。CLI 的起点也是统计起点，需要单独
预热区间时使用上面的 API。原生安装用户优先使用网页，无需另装 Python。

## 怎样解释结果

正/负 IC 表示本样本的同向/反向关联，不证明因果关系或样本外盈利。
t 值采用普通样本均值标准误，未调整重叠持有期的序列相关或多重检验；
不能凭 `|t| > 2` 就宣称发现有效因子。常数因子/收益的相关性未定义，不应报告为强 IC。

不同持有期、年份、证券池、预处理与因子版本都应分别记录。先看样本覆盖、空值与
预热，再看符号和稳定性，最后放入含成本的[策略回测](backtesting.md)。
