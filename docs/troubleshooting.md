# 常见问题与故障处理

先确认安装版本、平台架构和服务状态，再查看具体任务/策略错误。保留报错时间、
报告或任务 ID、脱敏参数与相关日志片段，避免用重新初始化或删库掩盖问题。

| 现象 | 检查与处理 |
| --- | --- |
| 找不到 `millionaire-ce` | macOS 默认命令在 `~/.local/bin`，可先用完整路径；Ubuntu 检查包安装结果；Windows 用控制器快捷方式或[安装 Python 路径](operations.md) |
| 浏览器打不开 | 确认服务运行、地址/端口正确、没有第二实例占用；服务器远程访问优先使用[SSH 隧道](native-installation.md) |
| 一直显示初始化 | 完成 wizard 的管理员密码和数据下载步骤；检查服务账户的目录权限与任务错误 |
| `admin` 无法登录 | 系统没有默认密码；使用 wizard 中设置的密码，确认浏览器访问的是同一个服务/配置目录 |
| token 正确但下载失败 | 核对具体接口权限、限频、日期和网络；保存错误中的接口名，不要只反复替换 token |
| 下载进度停住 | 查当前任务状态和错误，区分仍在等待、冷却、失败和 interrupted；修正原因后从对应维护页重试 |
| 日线有数据但 30 分钟失败 | 分钟数据是单独覆盖；检查证券市场、起点和内部缺口，北交所分钟路径需扩展 |
| 扫描不到新策略 | 使用绝对目录，确认服务账户可读；看语法/导入诊断，类需继承正确基类；修改后重启并重扫 |
| 提示周期冲突 | 按策略声明运行；日线不能临时改为 30 分钟，另建新策略验证 |
| 回测没有成交 | 检查预热、信号、可用现金、整手数量、T+1、涨跌停与拒单日志；无信号的运行可以合法无成交 |
| 回测结束日变短 | 对照本地日线覆盖和报告实际区间，先补数据再重跑 |
| LightGBM 无法导入 | 原生包核对安装完整性；源码安装启用 `ml30m` extra，macOS 源码运行还需 OpenMP，见[源码安装](installation.md) |
| “买入归因”为空 | 只支持声明预测解释能力的策略；数据/模型上下文不足或证券不在截面也可能没有结果 |
| 优化没有最优结果 | 检查候选错误、有效交易数和指标；空值/失败不能视为最优；先用小网格 |
| 仿真运行但不下单 | 查看交易时段、策略周期、最后行情时间、订阅范围、预热和系统风险事件 |
| 腾讯演示已到期 | 期限不能续开；接入用户行情扩展，配置并重启服务 |
| 扩展启用失败 | `quote-provider status` 找到实际文件，检查工厂和 `start/stop`；失败不会自动换源 |
| 关闭控制器后仍运行 | 这是预期行为；要停止后台工作需在控制器中停止服务 |
| 重启后状态看不懂 | 核对运行规格、活动委托、处理中的 intent 和行情新鲜度；未知结果先对账，不手工重复提交 |
| CE 没有实盘/三重障碍 | 本版范围如此，不通过改旧配置启用；收益归因和 AI 审计另见[规划](roadmap.md) |

## 反馈问题

在 [GitHub Issues](https://github.com/zillionare/millionaire-ce/issues)提供：版本、操作系统与
架构、原生/源码安装方式、最小复现步骤、期望/实际结果、任务/报告 ID 和脱敏日志。
不要上传 token、管理员密码、完整认证数据库或真实账户凭据。
日志和备份位置见[运维](operations.md)。
