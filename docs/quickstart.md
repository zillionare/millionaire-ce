# 快速开始

第一次使用，先完成一个日线策略的短区间回测，再研究 LightGBM。这样可以分别确认
安装、数据和策略运行都正常，不必一开始就下载全市场分钟数据或训练大模型。

## 准备

准备一台支持平台的电脑、可写的数据目录、Tushare token 及相关接口权限。
没有实时行情也可以回测；持续仿真需要另外配置实时行情源。
腾讯 30 天演示源是可选项，和历史数据初始化相互独立。

## 完成第一条使用路径

1. 按[安装说明](native-installation.md)安装对应架构的原生包，打开控制器并确认服务运行。
2. 点击控制器中的打开网页，或访问 `http://127.0.0.1:8130`。
3. 按[初始化指南](initialization.md)完成 wizard：设置数据目录、管理员密码、行情选择和
   Tushare 数据源，等待历史数据任务成功。首次使用的用户名为 `admin`，没有默认密码。
4. 登录后打开顶部“策略”。如列表为空，点击“扫描策略列表”；内置示例会自动参与扫描。
5. 选择 `DualMAStrategy`，按[回测教程](backtesting.md)在已有数据覆盖内运行。
6. 打开“收益概述”“交易详情”“每日持仓”“日志输出”，确认运行结束且无失败信息。
   策略没有发出信号时可以没有成交，这并不等于运行失败。
7. 再按[仿真教程](paper-trading.md)转入仿真，检查行情时间和运行状态。

本轮成功的判断是：可以重新打开同一份回测报告，看到相符的配置/区间和账户结果。
出现错误时优先检查任务和报告中的具体原因，见[故障处理](troubleshooting.md)。
