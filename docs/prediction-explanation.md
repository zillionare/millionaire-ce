# 预测解释与收益分析

本版的 SHAP 回答“这些因子如何影响本次模型分数”，并不等于完整策略收益归因。
回测报告中的收益、成交和持仓可以用于结果分析；通用收益分解属于[下一版规划](roadmap.md)。

## 打开单次决策解释

1. 完成 `MLMomentumReversalStrategy` 回测并打开报告。
2. 进入“交易详情”，点击成交对的 K 线入口。
3. 在交易面板查看“买入归因”或“卖出归因”，以及“特征 / 特征值 / 归因权重”。
4. 对照证券、决策日、训练/选池日期和该次使用的配置，理解输入与分数。

是否显示解释由策略能力决定：策略声明 `ATTRIBUTION = "shap"` 并实现预测解释接口。
普通双均线没有这一模型能力；不能因其没有 SHAP 面板就认定策略运行失败。
数据不足、证券不在截面或无法重建上下文时可能没有解释，不能把缺失当成零贡献。

## 怎样读 SHAP

正贡献表示相对该模型基准把分数向上推，负贡献相反；它不是该因子赚了多少元。
当前示例将预测分数和贡献按截面尺度处理，应在同一模型/截面口径下比较。
因子相关时，贡献分配会受特征组合和模型影响，不能把贡献大小直接当作独立因果效应。

例如某因子推高买入分数，随后股票下跌，二者并不矛盾：解释的是当时的预测，
实际收益还受到选股、权重、执行时点、成交价格、费用和后续市场变化影响。
卖出也可能来自不再入选 top_k，不能将所有退出都理解为一个负向 SHAP 阈值。

## 保留可复现上下文

保留当时的策略和因子源码、训练配置、因子集、证券池、数据与模型版本。
历史解释需要重建相应训练/选股过程；源码或数据发生变化后，重新计算的解释不能
直接当作旧运行的不可变审计记录。

## 下一版补什么

下一版拟提供与模型无关的账户/资产/交易/成本收益归因，对账权益变化，处理外部
现金流、公司行为、多期收益贡献及明确残差。SHAP 继续作为预测解释保留，二者并列。
本版不会通过改名把现有 SHAP 声称为已完成这些能力。
