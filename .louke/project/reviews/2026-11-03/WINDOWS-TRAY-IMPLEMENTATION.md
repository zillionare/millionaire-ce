# Windows 系统托盘服务控件

日期：2026-11-03。

## 交付行为

Windows 原生安装器附带 `MillionaireTray.exe`，使用 WinForms NotifyIcon 提供常驻托盘：

- 安装后以原用户身份启动，公共 Startup 快捷方式使控件在用户登录后自动启动。
- 右键查看状态、启停服务、打开网页与日志目录；双击打开网页。
- 普通运行使用 asInvoker；查看状态、打开网页无需提权，启停服务单独请求管理员授权。
- 退出托盘控件不停止或重启服务。开始菜单、桌面快捷方式与 CLI `control` 可重新打开。
- 每个 Windows 会话使用一个实例，多个登录会话可以各有一个托盘入口。
- 升级/卸载通知托盘退出；卸载移除本安装创建的登录、开始菜单与桌面快捷方式，保留用户数据。

控件从实际 WinSW XML 读取服务 ID 和日志目录，以安装目录确定 Python 运行环境。
服务名、安装目录和数据目录不硬编码为测试或生产默认值。
退出通知可跨登录会话发送，其操作仅关闭 UI；服务继续由 SCM/WinSW 管理。

构建使用 Windows 自带 .NET Framework C# 编译器，产物为 x64 WinForms 程序，
没有新增 Python GUI 依赖。窗口控制器仅在没有原生程序的源码环境继续作为后备；
Tkinter 改为创建窗口时才导入，原生控制器加载不要求 Tk。

## 验收证据

实体机：用户授权的 `192.168.0.103`，Windows 10 `10.0.19045`，AMD64。
安装、配置、模拟数据与报告均放在该机器的系统临时目录，使用独立 `millionaire-ce-ci` 服务。

1. 原生安装全流程通过：干净安装、菜单启停、服务强杀后恢复、覆盖升级、默认卸载保留配置及扩展。
2. 验收驱动直接引用安装包中发布的托盘程序集，实际驱动菜单，检查浏览器/日志目标和退出动作。
3. 登录 Startup 快捷方式存在；同一会话重复启动退出，保持已有实例。
4. 退出实际安装的托盘程序前后，健康接口返回相同后台服务 PID。
5. 单独在交互登录桌面会话 **2** 运行托盘，验证其会话 ID 同为 **2**、运行用户未提权，
   普通用户可查询服务为 `Running`；跨会话退出通知成功，服务 PID 不变。
   临时桌面检查计划任务在验证后删除，测试安装也已卸载。

初次单实例验收误以为安装器与 SSH 共用会话。实体机安装器会把控件投放到登录桌面，
SSH 在会话 0；已修正为先在当前会话等待命名 mutex，再验证同会话重复启动。
这与用户每个登录会话各有一个托盘入口的行为一致。

本地 18 项相关单元测试通过，无 skip/xfail；完整 Python 生产质量扫描、严格文档构建、
目录布局、diff 空白检查通过。Windows 编译和安装验收已接入既有原生 CI job，job 名称不变。
未运行远程三平台 GitHub Actions，未重启/注销用户机器，也未手工点击标准用户的 UAC 授权提示。
Windows 11 桌面实机验收仍需独立证据。
