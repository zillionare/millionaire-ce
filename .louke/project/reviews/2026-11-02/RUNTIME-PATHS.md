# 运行路径防回归与 agent 约束

本轮补齐上一轮目录整理遗漏的生产入口，而非仅移动已经生成的文件。

- `init_data` 原来要求位置参数并直接 `Path(home)`；空字符串会成为当前工作目录。
  现支持省略/None/空白，先初始化配置数据库以读取 wizard 保存的目录，再使用环境变量
  与系统临时兜底。`init_db=False` 保留由调用者管理数据库的契约。
- 未配置行情目录时，POSIX 使用 `/tmp/millionaire-ce/runtime-<用户摘要>/market`；
  Windows 使用系统临时目录。路径不随当前目录改变；不同用户不共用默认行情目录。
- 统一校验源码树内的行情/配置/数据库/模型输出，拒绝相对路径与符号链接绕过。
  SQLite 的 `:memory:` 仍可使用。常规持久配置目录与已有数据不迁移。
  服务安装也在写入前检查输出目录，阻止源代码虚拟环境安装 Windows 服务时将
  `millionaire-service.xml` 写到仓库根目录，或把服务数据配置为源码目录。
- `daily_basic` 改为延迟读取有效目录；ML 自动连接和 replay 脚本移除独立硬编码默认值。
  wizard 展示有效默认值并说明临时目录口径；macOS 原生安装器明确选择持久行情目录。
- `start.sh` 读取 `QUANTIDE_LOG_HOME`，无配置写入临时项目子目录，不再写平铺的
  `/tmp/millionaire.log`。
- pytest 在应用导入前隔离配置和行情目录，避免 session key、账户数据库、模型目录等
  导入副作用写入真实用户 profile。报告和缓存继续使用既有外部产物配置。
- 新增根 `AGENTS.md`，约束 agent 的构建、报告、日志、截图、缓存与审查材料归属，
  要求修复生成入口而非事后清理或添加 ignore。布局门禁增加数据库/sidecars、日志、
  模型与覆盖率报告等已知运行产物。

回归覆盖冷启动读取已保存配置、空值、环境、临时兜底、工作目录变化、用户隔离、
Windows 原生临时目录、symlink、运行写入器拒绝源码目录及内存数据库兼容性。
验证结果以本次提交 CI 及系统临时目录中的报告为准，不改变历史报告的计数。
