## 同期发现并修复的 Windows 竞态

此前 push CI `41424346624` 的 Windows 安装验收失败。WinSW 日志显示，stop 命令
返回时服务仍在 STOP_PENDING；随后的 start 被判为已启动，旧进程稍后退出，导致
健康检查等不到新服务。PR CI 的另一运行成功不能消除这个实际竞态。

服务管理现在直接查询 Windows SCM 的数值状态，停止命令在 SERVICE_STOPPED 后才
返回；启动遇到 STOP_PENDING 会先等待；卸载也等待停止完成。查询使用原生 API，
避免依赖本地化的 sc.exe 文本，并在成功/失败路径关闭 SCM 句柄。
新增回归覆盖延迟停止、停止中启动、卸载顺序、错误、超时与句柄清理。
最终 Windows 安装证据以本轮 PR CI 的实际产物验收为准，不以本机 mock 替代。

## 发布边界

手册首稿可供审阅；源码分支的内容不代表新版本已经发布。没有创建 tag、合并 PR、
部署 Pages 或替换 mini-two 服务。真实 Release 下载、三个平台按最终手册逐步操作、
真实历史数据的完整 wizard 导入仍需要与实际交付版本一起验收。
本轮以代码核对、可执行示例和应用集成测试验证内容，没有新增截图验收证据。

公开的现有限制仍包括缺少有效限价时部分路径跳过检查、未取得完整断电/多交易日
现场证据、未签名安装包与全仓类型检查；文档没有把这些限制隐去。
