# 发布前的目录与因子检验整理

## 目录归属

| 原位置 | 新位置/行为 |
| --- | --- |
| `data/` | 原四个固定样本逐字节迁至 `tests/assets/market_data/`，测试与 stub 改用该路径 |
| `packaging/` | 安装器源码、模板与许可迁至 `scripts/packaging/` |
| `review/` | 迁至 `.louke/project/reviews/`，保留历史报告与证据，修正活动文档引用 |
| `dist/`、`quality-reports/`、`site/` 及旧缓存 | 原文件保留至 `/tmp/millionaire-ce/workspace-cleanup-…`，具体见 `layout-migration.json` |
| 新生成产物 | POSIX `/tmp/millionaire-ce/<工作区摘要>/`，Windows 原生临时目录；显式输出也拒绝 checkout 内部路径 |

`scripts.artifact_paths` 统一子进程环境与 CI 路径。质量报告、coverage、测试缓存、
构建 staging、包、安装器证据和站点均在 checkout 外；安装 staging 自动清理。
用户持久化配置/真实行情留在各服务的数据目录，不迁入易失的 `/tmp`。
目录回归检查发现交易测试直接调用 FastHTML 默认工厂会重新创建根目录 `.sesskey`；
该测试改用显式测试专用密钥，生产持久会话密钥仍由配置目录管理。

质量检查新增布局门禁；工作流在产生文件后复查根目录。分发校验拒绝开发记录和
生成物，合法 `quantide/data` 模块和 `scripts/packaging` 源码不受误伤。
发布准备使用外部路径，手工 Release 现在也验证下载/重整阶段，但发布步骤仍仅 tag 触发。
可选 PyPI 上传使用宿主 Twine 读取外部路径，避免 Docker action 无法看到宿主 `/tmp`。

## 现有因子能力与修复

本版已有 `alphatest` 与因子台账，包含 Rank IC/t 值、十分位前瞻收益、分年与批量检验。
新增用户指南说明入口、最低截面 100、前瞻时序、预热、并列值、空组、t 值限制和缓存。

文档核对发现原先双 argsort 将并列值强制拆开，可能使常数因子出现虚假相关；
改为平均秩。批量检验从所有因子共用完整行掩码改为逐因子独立有限值掩码，
避免一个缺失因子使另一个有效因子的 IC 消失。
台账首尾组差按实际 D1/D10 取值，缺组不冒用其他组；CLI 增加数据目录参数并默认读配置。
新增回归使用独立解析相关值、常数、并列分组和不同因子的缺失样本验证。
