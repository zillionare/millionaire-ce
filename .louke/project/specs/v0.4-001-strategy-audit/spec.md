## 1. 目标与本版边界

让用户和 AI/agent 能用统一框架检查因子与策略，输出可复现、可定位错误的审计证据；
让所有通过标准交易路径产生的策略结果具备可对账的收益归因，不依赖策略是否使用 ML。
审计提供证据，不能证明任意程序不存在全部错误，也不构成收益保证。

本版 `0.3.0` 保留已实现的回测/仿真/HTTP 模拟柜台、策略固有周期校验、参数优化与
LightGBM 预测解释；不把下一版功能列成本版发布硬条件。已发现的账户、撮合和数据
正确性问题仍按本版缺陷处理，不能因为新增审计被排到下一版而豁免。

CE 不增加真实交易能力，不加入三重障碍、回撤卖出、成本止损等私有风险程序。
收益归因与通用审计属于 CE 框架能力；真实券商适配仍由用户或宿主负责。

## 2. 使用路径

1. 用户向 AI 描述因子公式或策略，选择框架模板并声明数据、时间和周期契约。
2. AI 生成实现及普通用例；框架使用独立维护的 oracle、对照与变异集执行审计。
3. 报告给出 PASS、FAIL 或 INCONCLUSIVE，列出失败时刻、标的、输入和差异。
4. AI 根据报告修正；每次源码、配置或输入数据变化都生成新的运行标识。
5. 将通过审计的策略用于回测及仿真，并用收益归因解释结果来自哪些资产、交易与成本。

## 3. 功能要求

### FR-4001：因子与策略契约

因子声明唯一 ID、版本、输入字段和单位、输出列/类型、预热期、可用时间、缺失值规则、
依赖和随机种子。输入以证券和时刻唯一标识，要求按证券/时间正确排序；重复键、非有限
有效值、跨证券串算、未来数据访问、周期冲突均须有明确诊断。

策略的 `BAR_INTERVAL` 是固有属性，下一版支持 `1d`、`30m` 与 `1M`，不能被运行参数改写；
各周期是独立审计对象。本版仍只支持前两个。报告覆盖因子输出、信号、订单意图和账户事实。
合法不交易、预热中无输出和计算失败必须区分，不能把三者都记为通过。

### FR-4002：未来扰动测试

对多个预先指定的截断点 `t0`，保持当时可得的信息不变，把可用时间晚于 `t0` 的输入
分别替换为合法随机值、零值及极端合法值，并执行完整因子/训练/选股/信号流水线。
零值不适用于正价格约束的输入时使用合法哨兵，扰动方案必须写入报告。

在相同环境、固定随机种子与确定性计算配置下，`t0` 及之前的输出必须逐位不变：
索引、行序、dtype、空值掩码和有效值字节都比较，不能用近似误差掩盖未来依赖。
若执行器无法保证逐位复现，先报告确定性前置条件失败，不能降级为近似 PASS。

完整范围包括全样本标准化、截面排名、选股池/指数成分、复权、训练标签与模型、缓存。
冷缓存和热缓存均执行；每个扰动在隔离状态中重建，缓存不能使被测计算根本没有发生。
以数据的 `available_at`/公告时间为准，而非仅按记录的交易日切分。
不比较 `t0` 之后的成交和最终收益，因为未来价格变化本应影响这些结果。

### FR-4003：随机对照与植入信号

同时支持随机因子、保留截面/时间依赖结构的标签置换与已知信号的合成市场。
明确区分 Pearson IC 和 Spearman Rank IC；植入目标使用指定度量，不混用两者。
支持目标 IC 如 0.05，记录样本数、重复次数、种子集合、预期分布和实际置信区间。

随机因子的期望 IC 为零，但单次测量不要求恰好为零。统计阈值、显著性水平、容差、
样本量和多重检验修正须在验收前固定；检验功效不足返回 INCONCLUSIVE。
不能通过反复换 seed、放宽阈值或删除失败重复使结果通过。

在零漂移、受控暴露的合成市场中，对照回测的期望毛收益接近零，净收益接近负交易成本。
在真实市场中检查相对匹配基准/暴露的超额表现，不能把随机多头组合的原始收益必须为
负数当作正确性条件。用不同强度与正负方向的信号验证 IC 和表现的响应关系；
研究 IC 的测试与策略可执行性/净收益测试分开，不要求任意 0.05 IC 都变成固定利润。

### FR-4004：金标准小样本与独立对拍

提供可手算的 3 只股票 × 10 个交易日数据及逐行计算说明，覆盖预热、因子、标签、排名、
信号、订单、费用、现金、T+1 和净值。追加停牌、涨跌停、除权/分红、部分成交等独立
事件样本，避免在一个小样本内隐藏过多假设。

oracle 采用人工锁定表或独立实现，不能调用被测生产函数生成期望值。固定参考库
版本、指标定义、日期/收益频率、基准、无风险利率、费用、空值和年化约定；
可使用 alphalens/quantstats 的兼容版本或第二实现，对差异逐项说明。
无参考库时不能静默跳过核心校验；独立最小 oracle 应离线可运行。

### FR-4005：不变量

每个不变量声明适用的资产、账户与执行模型，至少覆盖：

- 无杠杆多头账户中，现金和持仓市值加总与权益一致；包含现金的权重和约为 1。
- 卖出数量不超可用持仓，T+1 按交易日生效，拒绝订单不改变账户事实。
- 停牌期间不发生正常撮合；原持仓可以继续存在，估值遵循明确的陈旧价格规则。
- 初始资金快照的净值为 1；首次交易费用后的日终净值可以低于 1。
- 订单与成交数量、冻结资金、部分成交和撤单余量守恒；client_order_id 重试不重复成交。
- 交易费、税和现金流不重复扣减；复权和公司行为不凭空创造收益。
- 换手率按明确的单边/双边、频率、杠杆和分母定义校验，不能统一套用固定上界。
- 信号、模型和因子仅使用决策时可得数据；策略周期与数据周期一致。

适用范围外返回 NOT_APPLICABLE 并说明理由；必需规则不能通过自行标为不适用绕过。

### FR-4006：变异测试

维护独立的关键变异清单：负向 shift/未来回填、全样本拟合、选股池使用未来成分、
按行而非按证券滚动、T+1 提前解锁、越过涨跌停、漏费用/重复费用、重复下单、
撤单丢失部分成交、错改策略周期、错误归因符号与收益链接。

关键、有效且非等价的变异必须全部被对应审计用例杀死。报告逐项关联需求、变异位置、
触发用例与失败证据；用环境崩溃/导入错误杀死的变异不能替代目标断言的失败。
等价、无法触发或工具无效的变异由人工给出依据，单独计数，不能自动归为杀死。

### FR-4007：通用收益归因

保留 SHAP 为预测解释，新增与模型无关的收益归因。至少按账户、策略、证券、交易、
日/月/全区间解释收益、成本与剩余项；同账户多策略依赖稳定的交易来源标识。
历史记录缺少来源时列入“来源未分配”，不能猜测分摊。

每日须满足：期末权益 − 期初权益 − 外部净流入 = 已解释损益 + 显式残差。
解释项至少包括期初持仓价格变化、期间交易、佣金/税费、现金分红与公司行为。
实现价与参考价的差异可作为执行成本再分解，但不能在净损益中重复扣除滑点。
拆股/复权转换保持财富守恒；缺少公司行为记录时报告数据不足及残差，不能补造事件。

同时支持金额贡献和收益率贡献。累计收益用时间加权收益及明确的多期链接，
不能把每日收益率或贡献简单相加冒充区间贡献。无外部流入时采用 Carino 链接：
`k_t = log1p(r_t) / r_t`，`k = log1p(R) / R`，`C_i = sum(k_t*c_it) / k`；
`r_t`/`R` 为零时取极限 1。外部现金流按事件分段后再链接，零/负净值等无效域须明确处理。

基准比较须使用同区间、同频率和可说明的费用/复权口径。行业/风格因子归因如提供，
必须使用当时可得的暴露和独立版本化的因子收益，显示模型残差；它不等于因果解释。
最低发布范围是完整的账户/资产/交易/成本对账与基准比较，不能用 SHAP 替代。

### FR-4008：AI/agent 可消费的报告

提供稳定 JSON 与可读 HTML/Markdown；包含代码/依赖/配置/数据指纹、环境、种子、
时区、周期、测试配置、运行标识、各项结果、统计口径与复现入口。
FAIL 至少给出首次差异的时刻/标的、期望/实际值、错误类型与最小输入片段。
仅对对应指纹和审计配置显示通过状态；改因子或配置后旧结果不能继续充当通过证据。
审计失败保留诊断，不自动“修复”策略、删数据或降低门槛。

### FR-4009：因子研究框架、产品入口与自动跟踪

本版已有 `alphatest` 和因子台账：Rank IC、普通 t 值、十分位前瞻收益及分年汇总。
下一版复用 `alphatest` 的计算基础和 API/CLI，在研究与策略之间增加“因子”一级入口，
用分组侧栏、因子卡片/检验报告双 tab 与后台持久快照取代旧台账宽表。
旧 `/system/alpha-ledger` 在该版本移除且不重定向；当前发布版用户文档在功能落地前
仍说明现有入口。保留研究核心的轻量性质，不把完整 Alphalens 作为运行依赖。

接受规范面板/用户因子，明确周期、预热、区间、价格/复权、前瞻窗口、真实交易日
序号、证券池、缺失/无穷值和并列值规则。单因子与批量结果必须一致，增加另一个
含缺失值的因子不能改变原因子的样本和结果。
最低截面样本数可配置且记录在报告中；不足样本显示原因，不能让小样本 oracle 被静默跳过。
提供 Pearson/Rank IC 序列及汇总、有效样本与排除原因、分组前瞻收益及首尾组差、
分期稳定性；ICIR 等统计公开定义，不把普通 t 值当成已完成相关性调整。
报告根据实际日期动态展示，不能沿用当前台账固定的 2023–2026 年列。

用一个自定义因子串起“公式 → 小样本 → 因子检验 → 四类审计 → LightGBM/策略”，
研究本身不要求先改核心 catalog；进入自动跟踪才须提供目录元数据和版本。
JSON/可读报告包含版本和数据指纹，供 AI 消费诊断。
研究 IC、无成本分组收益与可执行净收益分别说明，复用独立 oracle 和对照。

每个登记因子默认启用一套跟踪方案，可关闭、覆盖或恢复默认；固定因子公式参数与
可编辑的评价参数分离。初次回填、每日数据维护后的更新与自定义检验均为后台任务，
页面只读完整快照。首版自动跟踪采用日线、全 A 股；其他周期的研究核心采用
显式 `holding_bars`，不改变策略固有周期。

详细需求 FR-4301～4362 与 NFR-4301～4308 见[因子研究专题](factor-research.md)，
包含 t1 到 t(h+1) 的标签成熟、逐持有期截止日期、日等权分层口径、共同样本衰减图、
临时区间转滚动窗口、增量/全算对拍、并发发布和中断恢复合同。
描述性研究结果不能代替 AuditReport 的 PASS，也不能将按历史结果选择方案称为样本外证据。

### FR-4010：真正的月线周期示例

交付 `MonthlyMAStrategy`（规划名），固定声明 `BAR_INTERVAL = "1M"`，用 3 月/12 月
均线交叉演示简单月线逻辑。它不是日线策略内部在月末触发的替身，不能在启动时改为
日线或 30 分钟；其他策略也不能通过一个参数直接改成月线。

现有 `FrameType.MONTH` 枚举不代表月线执行已经可用。下一版须打通月线聚合、
历史/实时视图、时钟、回测、Paper、HTTP 模拟柜台、报告和参数优化。
周期标识区分 `1M`（月）与 `1m`（分钟），禁止统一转小写后混淆。

从已验证日线按交易日历生成闭合月线，记录月末实际交易日及数据可用时间。
未结束月份作为单独 forming bar，不进入已完成月线信号或训练。
月长、闰年、节假日、跨年、上市/退市、停牌/缺月、复权和成交量/金额聚合须明确；
不能固定加 30 天，也不能把周末/节假日自然月末当成交日。缺月不虚构价格。

默认在完整月线结束后产生信号，于下月第一个交易日开盘模型执行。委托和资金仍使用
真实日/盘中行情与股票规则，月聚合不能解锁 T+1 或伪造流动性。
比较 3/12 均线前后交叉至少需要 13 根闭合月线；预热不足明确不交易。
跨月意图持久化、重启无重复下单，三个 Broker 路径有人工账户对拍。
教程涵盖日线复用/聚合、运行、核对信号与成交、优化和恢复。本版不提前开放月线菜单。

## 4. 非功能与发布要求

- NFR-4001：使用独立离线 fixture；核心审计不依赖 Tushare、腾讯或真实券商。
- NFR-4002：确定性单线程参考路径与统计多种子路径分开；随机性、线程和超时可复现。
- NFR-4003：沿用当前复杂度、重复代码、文件/行长度和测试覆盖门禁，不放宽预算。
- NFR-4004：官方因子、策略模板与 HTTP 模拟柜台在下一版发布时须通过适用审计；
  必需项目空执行、skip、xfail、INCONCLUSIVE 均不能作为通过。用户审计默认不修改现有账户。
- NFR-4005：每次 PR 跑确定性/小样本与关键变异；周期检查执行完整统计样本，
  下一版发布对同一 ref 跑完整统计与变异硬门禁，不能只引用过期历史报告。
- NFR-4006：审计当前进程不等于对不可信 Python 的安全沙箱；AI 工作流只加载用户
  明确选定的代码，不自动执行报告中的命令或生成真实订单。

## 5. 里程碑与完成定义

1. 契约、报告格式、3×10 oracle 与收益台账对账。
2. 未来扰动、冷热缓存、随机与信号植入、适用范围明确的不变量。
3. 关键变异、指标对拍、多期收益归因与 UI/agent 报告。
4. 按 FR-4009 复用当前模块，完成结构化元数据、单方案、版本化后台任务与快照，
   再接通一级导航、卡片/报告、自定义检验及 AI 报告；详见因子研究专题的子里程碑。
5. 月线聚合/时钟、固定月线示例、三路径对拍与跨月恢复。
6. 同一因子从 AI 生成、审计失败、修复到仿真的完整教程及三平台验证。

需求与 AC 双向追踪，所有必需验收通过后才称“AI 因子/策略审计可用”；
收益归因须独立对账并经多期/事件样本验证后才称“通用收益归因可用”。
因子自动跟踪须同时通过 AC-4016/4017 与 AC-4301～4320；界面存在或任务完成
本身不构成统计正确性的验收。整个计划仍为未实现规格，不是本版发布新增硬条件。
