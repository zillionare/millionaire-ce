# 下一版验收标准

状态：规划，未执行。规范来源：[spec.md](spec.md)。以下均为下一版要求，非本版通过声明。

| AC | 对应需求 | 验收行为 |
| --- | --- | --- |
| AC-4001 | FR-4001 | 日线策略被要求按 30 分钟运行时明确失败；合法日线/30 分钟策略各自可审计。重复键、跨资产滚动、错误单位/缺失契约都有诊断。 |
| AC-4002 | FR-4002 | 正确因子在多个截断点、三类合法未来扰动和冷/热缓存下，历史输出字节一致；注入未来 shift、未来选股池或全样本标准化的实现全部失败。 |
| AC-4003 | FR-4002 | 因子不变但训练标签/模型或缓存使用未来数据时，信号级检查仍失败；失败定位至首次差异，不因缓存命中而虚假通过。 |
| AC-4004 | FR-4003 | 独立预定种子集的随机因子与置换标签符合预定零 IC 分布；0.05 及其他正/负信号在预定置信区间/功效下被恢复，Pearson 与 Rank IC 分别验证。 |
| AC-4005 | FR-4003 | 零漂移合成市场随机对照毛收益近零、净收益近负成本；真实多头市场只检查匹配基准后的超额表现，不能要求原始收益必为负。功效不足明确为 INCONCLUSIVE。 |
| AC-4006 | FR-4004 | 3×10 数据逐步输出与人工表一致；事件样本中的费用、T+1、停牌、涨跌停和公司行为正确。独立 oracle 无生产计算依赖。 |
| AC-4007 | FR-4004 | 与固定参考库或第二实现对拍；指标差异对应显式口径或缺陷，不通过修改期望值掩盖。核心路径无参考库也能离线验证。 |
| AC-4008 | FR-4005 | 资金/数量/权重守恒、拒单无副作用、T+1、client_order_id 幂等全部覆盖；停牌持仓合法保留但不撮合；首个资金快照而非任意日终净值等于 1。 |
| AC-4009 | FR-4006 | 关键非等价变异逐项被正确断言杀死，报告给出对应 AC 和失败证据；存活关键变异阻断，导入崩溃不能冒充有效杀死。 |
| AC-4010 | FR-4007 | 非 ML 策略和 LightGBM 策略都能按资产/交易/成本归因，并与账户权益变动对账；未分配来源、缺公司行为和剩余项显式显示。 |
| AC-4011 | FR-4007 | 现金流、分红/拆股、零收益日、正负收益、多期复利与 Carino 链接有人工小样本；累计贡献之和等于区间收益，滑点不重复扣除。 |
| AC-4012 | FR-4007 | 同区间基准比较可复现；SHAP 与收益归因分别展示，未实现行业/风格模型时不声称已支持。 |
| AC-4013 | FR-4008 | JSON 与可读报告内容对应，首次错误含数据位置/期望/实际/复现条件；任一来源指纹改变后旧通过状态失效。 |
| AC-4014 | NFR-4001/2/4/5 | 官方模板及柜台在 macOS ARM64、Ubuntu x86_64、Windows x64 完成确定性核心审计；完整统计与变异发布门禁非空通过，不接受 skip/xfail/INCONCLUSIVE。 |
| AC-4015 | NFR-4003/6 | 现有质量预算保持通过；审计不触发真实交易，不修改未选择的代码或用户账户，也不自动执行 AI 修复结果。 |

金额采用明确币种/最小单位；浮点计算容差由 fixture 的累积误差预算固定，并记录最大
绝对/相对误差。未来扰动的历史逐位比较不使用此金额容差。
统计阈值的确定方法见[测试计划](test-plan.md)，不得从被测结果反推可通过的阈值。
