# 数据源能力管理与组合配置

状态：下一版规划，未实现。版本目录为规划标识，不新增本版发布条件。

## 用户目标

用户分别选择历史行情、实时行情和参考数据，不必理解内部组件，也不应因为
默认推荐 Tushare 就误以为所有账号已含 ST、限价、实时或分钟权限。
已有分钟权限的用户可以直接接入；没有实时权限的用户仍可研究回测。

## 本版基础与边界

本版六步向导已先配置/检查历史源，再按需选择实时方案，最后显式下载。
权限检查覆盖初始化实际依赖，区分明确权限不足、密钥无效、限频、网络失败、
空响应、字段缺失。可用的 Tushare `rt_k` 自动接入；`rt_min` 仅检测、需扩展。
腾讯演示保持默认关闭、一次固定 30 天；到期只停止演示源，不替用户续期。
实时源在启动时装配，配置变更需要重启服务；当前不支持通用多源组合与热切换。

## 能力合同

adapter 声明数据集、市场、证券类型、周期、历史起点、时区、单位、字段、
可得时间、调整方式与限频方式。区分股票与指数、快照与闭合分钟、历史与实时，
不能凭 `close` 列存在就宣称可供交易，也不能把历史数据冒充当前行情。

凭证 schema 提供密码型字段、校验与脱敏规则；检测契约返回结构化诊断，
原始异常不得回显 token。检测缓存绑定凭证摘要、能力配置和样本区间，
支持强制重检；账号升级后无需更换 token 即可观察新权限。

多源组合按数据集绑定唯一主源与显式备用源。策略只消费标准数据，
供应商转换停留在 adapter；备用源不得改变单位、复权或时间语义。

## 实施范围

1. 分别配置历史日线/分钟、实时快照/分钟、证券参考数据与限价/复权来源。
2. 接入 `rt_min`、`rt_min_daily` 与指数实时适配，调查权限、配额和真实字段合同，
   在取得授权后验证，不把独立接口权限混为一谈。
3. 检测分阶段报告权限、字段、标的/日期覆盖、时间戳、持续时效与频率。
   区分休市无新数据、真实空集、限流和拒绝授权；有限重试，不做探测风暴。
4. 最新价、当日限价与复权基准共同形成可交易状态。`pre_close` 必须结合历史
   原始收盘和因子；缺失/过期时阻止依赖它的交易，不造零值或沿用昨日限价。
5. 源断流诊断覆盖到策略/订单入口；来源恢复时显式核对时效及未闭合 bar，
   不把不完整的中途采样桶视为完整历史分钟。
6. 安全热切换：先验证新源、等待旧源停止、切换单一发布所有权，失败回滚；
   保存切换时间和来源证据，避免双发、重复成交、旧请求晚到污染。
7. 持久配置/凭证位于用户配置目录，缓存和报告使用标准外部目录；
   用户可导出脱敏能力报告，升级/卸载保留用户扩展与数据。

## 验收

- 默认账号、独立付费权限、失效 token、网络失败、限频、空响应分别有离线合同测试。
- 只有分钟权限时直接使用分钟适配，不建议用户额外购买快照权限。
- 股票/指数、跨日限价、除权日、时间戳偏差与午休/节假日均有金标准样本。
- 断流、乱序、重复与过期消息、切源失败、停止后晚到全部验证；缺行情不下单。
- 同一标准行情接入既有三模式一致性验收，不因来源不同改变策略周期或撮合合同。
- 真实源测试使用环境凭证、小样本与明确时段；权限样本通过不能代替持续运行证据。
- 安装后的向导可完成：只回测、已有实时源、30 天演示、演示到期自行扩展四条路径。
- CE 不因此增加真实交易或私有风控；文档分别标明 CE 和 millionaire pro 的范围。
